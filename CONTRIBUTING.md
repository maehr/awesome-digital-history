# Contribution Guidelines

Awesome Digital History is a community-maintained directory of digital history resources. Contributions are welcome.

## Source of truth

- Canonical entries live in `entries/*.qmd`
- `README.md` and `index.qmd` are generated from those pages
- Screenshots live in `assets/screenshots/`

## How to contribute

### Issue

1. Open the [issue tracker](https://github.com/maehr/awesome-digital-history/issues/).
2. Check for an existing discussion.
3. Use the addition, change, or removal template.

### Pull request

1. Fork the repository.
2. Edit the relevant `entries/*.qmd` files and related docs.
3. Run `npm install`.
4. Run `npm run check`.
5. If you changed source URLs or added entries, run `npm run screenshots`.
6. Submit a pull request against `main`.

## Code of Conduct

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md).
